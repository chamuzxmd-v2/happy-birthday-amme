# 🎉 Happy Birthday Website

A simple, colorful **Happy Birthday** webpage with background music 🎶  
Perfect for sharing with friends, family, or loved ones.

## 🌐 Features
- 🎂 Beautiful birthday design
- 🎵 Auto-play & loop background music
- 🖼️ Large centered image
- 📱 Mobile & desktop responsive
- ⚡ Fast & lightweight (HTML only)

## 📂 Files
- `index.html` – Main website
- `README.md` – Project info
- `LICENSE` – MIT License

## 🚀 How to Use
1. Download all files
2. Open `index.html` in a browser
3. Edit text, image, or music if needed
4. Upload to:
   - GitHub Pages
   - Netlify
   - tiiny.host
   - Any static hosting

## 🛠️ Customize
- Change birthday message text
- Replace image URL
- Replace music MP3 link
- Edit colors & animations in CSS
